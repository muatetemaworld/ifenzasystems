Copilot ya mueve el ratón: GitHub abre «computer use» para manejar programas de escritorio y, una semana después, los encierra en una caja

El 1 de octubre GitHub puso en vista previa pública la capacidad de Copilot para manejar aplicaciones de escritorio en macOS y Windows desde la CLI y la app. El 7 de octubre activó para todos el «local sandboxing», que aísla ficheros, red y credenciales de lo que ejecutan los agentes. Veintinueve entradas de changelog en 23 días.

Tomás GrauCódigo abierto y GitHub · 24 de octubre de 2026

Si has leído un changelog de GitHub en octubre, has leído veintinueve. Entre ellos hay dos que cambian el oficio. El primero, del 1 de octubre: Copilot puede ahora leer el contenido accesible y el contexto visual de una aplicación de escritorio, hacer clic, escribir, pulsar teclas, hacer scroll, arrastrar y encadenar acciones entre varias apps. Está pensado para el software que no tiene API, ni CLI, ni integración MCP: el programa viejo que todo el mundo odia y nadie puede jubilar. Se activa en la CLI con «/computer on».

Viene desactivado por defecto. Copilot pide aprobación antes de controlar una app, las decisiones de «permitir siempre» se guardan en local y los administradores pueden deshabilitarlo. La documentación es inusualmente honesta: el agente «puede malinterpretar interfaces, elegir el control equivocado o repetir acciones». Recomiendan usar API, MCP, terminal o navegador cuando existan, y no dar «permitir siempre» en aplicaciones sensibles. Es el único manual que conozco que te pide que no lo uses si puedes evitarlo.

El segundo changelog, del 7 de octubre, es el contrapeso: local sandboxing en disponibilidad general, sobre Microsoft eXecution Container, que restringe el acceso a ficheros, red y credenciales de las herramientas y comandos que lanza Copilot. Sin coste adicional, en Windows, macOS y Linux. La misma semana entraron Claude Haiku 5.5 y los modelos locales de Ollama en el selector «/model», y el 15 de octubre el «agentic autofix» para alertas de code scanning.

Un dato para calibrar el entusiasmo: en OSWorld, el benchmark de 2024 para agentes que manejan un ordenador real, los humanos completaban más del 72 % de las tareas y el mejor modelo de entonces, el 12 %. Dos años después nadie publica el número de Copilot. Cuando lo publiquen, lo leeremos aquí.

Qué significa para tu pyme

Esto significa que tu programa de facturación de 2009, ese que no tiene API, empieza a poder automatizarse con un agente que lo maneja como un empleado. Con tres condiciones: vista previa, sandbox activado y aprobación manual en cada paso. Y nunca, de momento, en aplicaciones con datos bancarios o de clientes.

Si quieres ver si aplica a tu negocio, veinte minutos.
